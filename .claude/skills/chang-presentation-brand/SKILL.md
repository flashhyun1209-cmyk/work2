# 장동인 발표 브랜드 가이드

기준 디자인은 저장소 루트의 `chang7.html`이다. 새 산출물(슬라이드, HTML, 문서)은 이 파일의 색상·서체·구성을 따른다. 판단이 애매하면 `chang7.html`을 열어 같은 패턴을 재사용한다.

## 1. 브랜드 성격

- **신뢰감 있는 실무 전문가**: 40년 IT·컨설팅 경력(VISA, Oracle, Deloitte, EY 등)을 바탕으로 한 무게감.
- **"돈 되는 AI"**: 기술 자랑이 아니라 기업 성과로 이어지는 AI. 문제 해결보다 *문제 정의*를 앞세운다.
- **직접 해 보는 리더십**: CEO가 직접 코딩해야 AI를 이해한다는 메시지(국내 최초 'CEO를 위한 AI 코딩 강의').
- 톤은 차분하고 단정하게. 과장 수식어, 이모지, 네온·그라디언트 같은 '테크 과시형' 장식은 쓰지 않는다.

## 2. 색상 토큰

라이트를 기본으로 하고, 다크 모드는 같은 이름의 토큰을 재정의한다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#f7f6f3` | `#14161a` | 페이지·슬라이드 배경(따뜻한 오프화이트) |
| `--surface` | `#ffffff` | `#1c1f24` | 카드 배경 |
| `--text` | `#1d1f23` | `#e9e7e2` | 본문 |
| `--muted` | `#5d636e` | `#a2a7b0` | 보조 텍스트, 연도, 출처 |
| `--line` | `#e3e1db` | `#2e3239` | 구분선, 카드 테두리 |
| `--accent` | `#1f4e8c` | `#7fa8e0` | 주 강조색(딥 블루): 제목 보조, 링크, 연도 |
| `--accent-soft` | `#e6edf7` | `#1f2a3a` | 강조 배경(전문분야 칩 등) |
| `--current` | `#b4541b` | `#e8935c` | '현재'·'최신'·'운영 중' 표시(번트 오렌지) |
| `--current-soft` | `#fbeee5` | `#3a2a20` | 현재 직함 칩 배경 |

규칙
- 한 화면의 강조색은 `--accent` 하나를 기본으로, `--current`는 "지금 진행 중/가장 최신" 항목에만 쓴다.
- 배경은 순백(`#fff`)이 아니라 `--bg`. 카드만 `--surface`.
- HTML에서는 `:root`에 토큰을 정의하고 `@media (prefers-color-scheme: dark)`와 `:root[data-theme="dark"]` 양쪽에 다크 값을 둔다.

## 3. 서체

- **제목(H1·H2·슬라이드 제목)**: Noto Serif KR 600/700
- **본문·라벨**: Noto Sans KR 400/500/700
- 웹: `https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700&family=Noto+Serif+KR:wght@600;700&display=swap`
- PPTX 등 웹폰트를 못 쓰는 경우: 제목 *Noto Serif KR* → 대체 *나눔명조*, 본문 *Noto Sans KR* → 대체 *맑은 고딕*.
- 한국어 줄바꿈은 `word-break: keep-all`. 숫자 열(연도)은 `font-variant-numeric: tabular-nums`.

## 4. 레이아웃 패턴 (chang7.html 기준)

| 패턴 | 생김새 | 쓰는 곳 |
|---|---|---|
| Eyebrow | 작은 대문자 라벨, `--accent`, 굵게, 자간 0.08em (예: `PROFILE`) | 표지·섹션 머리 |
| 직함 칩 | 둥근 pill, `--current-soft` 배경 + `--current` 글자 | 현재 직함 나열 |
| 섹션 제목 | 세리프 제목 + 옆에 작은 영문 부제(`경력 Career`) | 모든 섹션 |
| 타임라인 | 왼쪽 연도 열(112px) + 오른쪽 기관(굵게)/역할(muted), 행마다 얇은 구분선. 현재 항목은 연도를 `--current`로, `현재` 배지 | 경력, 최근 활동 |
| 강조 카드 리스트 | `--accent-soft` 배경의 둥근 블록 | 전문분야, 핵심 메시지 |
| 책 카드 | 흰 카드 + 왼쪽 4px 컬러 바(최신은 `--current`, 나머지 `--accent`), 제목/부제/출판사·연도 | 저서 |
| 출처 푸터 | muted 13px, 기준일 + 출처 링크 | 모든 산출물 끝 |

모서리 반경은 카드 14px, 작은 블록 10px, 칩 999px. 그림자는 쓰지 않고 1px 테두리로 구분한다.

## 5. 슬라이드 적용 규칙

- 비율 16:9. 배경 `--bg`, 좌우 여백은 화면 너비의 약 6%.
- **표지**: Eyebrow(강연명/행사명) → 세리프 대형 제목 → 직함 칩 2~3개 → 하단에 날짜·행사장.
- **본문 슬라이드**: 제목 1줄(세리프) + 핵심 메시지 1문장 + 근거 3개 이내. 한 슬라이드 한 메시지.
- **연사 소개 슬라이드**: 현재 직함(칩) → 주요 경력 타임라인 5~6줄(최근순) → 최신 저서 1~2권 카드.
- 차트·도표는 `--accent` 단색 계열, 강조할 한 항목만 `--current`.
- 마지막 슬라이드에 출처와 기준일.

## 6. 문체·표기

- 존댓말, 짧은 문장. 핵심 메시지는 "~해야 합니다", "~가 핵심입니다"처럼 단정하게.
- 대표 키워드: 돈 되는 AI, 문제 정의, 현업 주도 AI 도입, AI 에이전트, CAIO, 조직문화 변화.
- 영문 기관명은 원어 그대로(Oracle, Ernst & Young, Deloitte Consulting). 국가 표기는 괄호: `Amadeus (독일)`.
- 학위: `University of Southern California 컴퓨터과학 석사 (Master of Computer Science)`, `서울대학교 공과대학 원자핵공학과 졸업`, `서울과학종합대학원 경영학박사 (Big Data)`.

## 8. 하지 말 것

- 위 표에 없는 직함·수치·수상 경력을 지어내지 않는다. 새 사실은 웹 검색으로 확인하고 출처·기준일을 단다.
- 장동인 본인 명의의 발언을 만들어 따옴표로 인용하지 않는다(공개된 인터뷰 문장만 출처와 함께).
- 로고·사진은 사용자가 제공한 파일만 쓴다. 없으면 이니셜 모노그램이나 텍스트 표지로 대신한다.
